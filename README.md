# Cartão Schmitt

Site do programa de fidelidade do Schmitt Buffet e Eventos (AABB Brusque):
<https://fidelidade.schmittbuffet.com.br>

- `index.html`: cadastro e cartão do cliente
- `toque.html`: o que abre quando o cliente encosta o celular no totem do caixa
- `caixa.html`: tela do caixa (PIN do atendente)
- `painel.html`: painel do dono
- `regulamento.html`: regulamento do programa
- `config.js`: endereço do servidor e funções comuns
- `estilo.css`: visual do site

O servidor e o banco de dados ficam no Supabase. Este repositório só tem as páginas, sem senhas nem dados de clientes.
